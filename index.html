Portfolio Overview

The selected artifact began as a CS-340 Client/Server Development project created in April 2026. The original Python dashboard connected to MongoDB and allowed rescue personnel to filter shelter records, inspect breed distributions, and view selected animals on a map.

Throughout CS 499, the same artifact is being enhanced in three categories so that the portfolio shows measurable growth from a functional classroom project to a more maintainable, efficient, secure, and professionally documented application.

Module Six publication

The Software Design and Engineering and Algorithms and Data Structures enhancements are now published. The Databases enhancement, Professional Self-Assessment, and corrected Code Review will be added for the final portfolio.
